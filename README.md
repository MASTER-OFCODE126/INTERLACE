INTERLACE

INTERLACE is an interactive, shader-driven visual experience inspired by modern creative studios like Dogstudio.
The project explores material transitions, hover-based interactions, and depth-driven animations using WebGL and real-time shaders.

✨ Overview

INTERLACE focuses on how UI interactions can influence 3D visuals in real time.

Hovering over text elements triggers smooth matcap transitions on a 3D model

Transitions follow a directional gradient instead of instant switches

Background imagery reacts alongside material changes for a cohesive visual feel

Animations remain smooth even during fast pointer movement

This project is not about static visuals — it’s about interaction as design.

🧠 Key Concepts Explored

Shader-based transitions using onBeforeCompile

Directional material blending (left → right)

GSAP-driven uniform animation

DOM → WebGL interaction bridge

Visual continuity during rapid hover changes

Creative coding workflows inspired by studio-grade websites

🎮 Interactions

Hovering over project titles updates:

3D model material (matcap blending)

Background imagery

Transitions are animated, not snapped

Leaving a hover completes the transition instead of reversing abruptly
